# ChainCert

Enterprise-grade Academic Credential Verification System built on Ethereum (Solidity smart contract + FastAPI backend relay + React frontend).

## Project Architecture

- `contracts/`: Solidity smart contract source (`ChainCert.sol`).
- `scripts/`: Hardhat deployment scripts (`deploy.js`).
- `api/`: FastAPI backend relay powered by `web3.py`.
- `frontend/`: React + Tailwind CSS Web3 dashboard.

## Environment Variables

The backend uses `api/.env` (see `api/.env.example` for defaults):
- `WEB3_PROVIDER_URL`: The RPC endpoint URL (e.g. local Hardhat node `http://127.0.0.1:8545` or a public testnet like Sepolia).
- `UNIVERSITY_ADMIN_PRIVATE_KEY`: Optional private key of the issuing university admin account — if unset, the service falls back to the first pre-funded local Hardhat account, which only works on localhost, not on a real testnet.

The frontend uses `frontend/.env` (see `frontend/.env.example` for defaults):
- `VITE_API_URL`: The URL of the FastAPI backend relay (defaults to `http://127.0.0.1:8000`).

## Contract Configuration (`contract_info.json`)

Note: `api/contract_info.json` and `frontend/src/contract_info.json` are auto-generated by running `npm run deploy` (see `scripts/deploy.js`) and must be regenerated after every fresh contract deployment, especially when switching networks (localhost vs Sepolia). Do not let these files go stale in version control or mistake them for a working live deployment.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   cd frontend && npm install && cd ..
   cd api && pip install -r requirements.txt && cd ..
   ```

2. Start local Hardhat testnet node:
   ```bash
   npm run node
   ```

3. Deploy smart contract:
   ```bash
   npm run deploy
   ```

4. Start FastAPI backend relay:
   ```bash
   # From api/ directory:
   uvicorn main:app --reload --port 8000
   # Or from project root:
   uvicorn api.main:app --reload --port 8000
   ```

5. Start React frontend:
   ```bash
   cd frontend
   npm run dev
   ```

## Known Limitations

- **No Automated Test Suite**: Automated unit and integration test suites are not included in this build.
- **Development-only Private Key Handling**: Storing or passing raw private keys in environment variables is intended for development and local testing only; production environments should use secure key management hardware or HSMs.
- **Contract Information State**: `contract_info.json` files must be manually regenerated via `npm run deploy` whenever contracts are re-deployed or deployed to a new network environment.
